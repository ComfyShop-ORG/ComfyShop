# 功能与使用

ComfyShop 是面向团队的开源自托管 RunningHub 替代方案，覆盖 ComfyUI 工作流发布、工作机接入、生成任务、逐次执行和成品管理。Web 和 Skill 通过同一个 FastAPI 服务访问平台数据。 [RunningHub 中国站](https://www.runninghub.cn/) · [RunningHub 国际站](https://www.runninghub.ai/)

## 账户与访问

- 简体中文、台湾繁体中文、英文、日文和韩文共用同一套 URL、账号、登录会话和工作机。手动选择的语言由浏览器记住，优先于浏览器的语言首选项和部署默认语言。切换语言时保留当前地址。界面、平台错误、官方内容和账号邮件使用解析后的展示语言，作者内容保留原文。
- 首页、搜索和作者页使用同一个公开目录。「我的」默认按当前账号读取记录。工作流分享链接使用 `/workflows/<id>`，作品和历史版本分别通过 `?work=` 和 `?version=` 打开。
- 在搜索框输入文字后，点右侧的「清除搜索」可清空当前关键词并继续输入。结果和团队操作记录可从工具栏点「清除筛选」，将该列表的筛选恢复为默认值。
- 在「我的 → 共享空间」填写 ComfyShop 账号名并授权查看。授权覆盖整个「我的」，包括现有及以后加入的栏目和记录。对方登录后可从「与我共享」或共享链接进入，浏览列表、详情、参数和媒体，也可下载界面提供的原件。修改、执行和授权管理由所有者操作。所有者可随时撤销授权，旧链接的后续读取也会被拒绝。
- 在登录弹框用账号和密码注册。邮箱选填，确认后用于找回密码。通过「账户 → 账号设置」可管理邮箱、修改密码或注销账号。
- 「账户 → 个人资料」可保存最多 32 个字符的昵称，留空时显示账号名。选择不超过 5 MB、2000 万像素的 JPG、PNG 或 WebP 后，在上层弹框中拖动、缩放并预览方形裁剪。点「保存头像」后立即更新，点「取消」返回个人资料。昵称单独保存，头像也可移除。账号菜单、作者页、工作流和作品显示更新后的资料。登录与作者链接继续使用账号名。作者发布工作流或作品后，访客可查看作者资料。
- 更换邮箱需打开新邮箱里的链接，点「确认绑定」。确认前已绑定的邮箱仍可用于找回密码。修改密码、管理邮箱和注销均需核对当前密码。
- 登录时可点「忘记密码」，使用已绑定的邮箱申请一次性链接。密码重置链接默认有效 30 分钟，邮箱确认链接默认有效 24 小时，可通过 [环境变量](../.env.example) 配置。未设置邮件服务时，链接写入服务日志。
- 修改密码会注销其他会话，重置密码会注销所有会话。两者都会撤销个人工作机和待兑换的接入申请，并将这些工作机上排队或执行中的任务标记为失败。ComfyUI 工作机可重置密钥后重新接入，RunningHub 需重新添加连接。注销会隐藏账号的工作流、作品、任务和成品，同时撤销工作机和会话。
- 访客可浏览公共工作流和公开作品。生成、收藏、上传、发布和下载工作流 JSON 需要登录。
- 首次访问默认使用深色。访客和登录用户都可以在页头切换全站外观和语言。宽屏显示独立入口，手机使用「显示与语言」菜单。当前浏览器记住选择，刷新和退出登录后继续使用。
- 页头和页面共用 1888 px 的默认宽度上限。登录后可在账号菜单开启「全宽布局（实验性）」，让所有页面使用窗口可用宽度，并保留页面边距和屏幕安全区。当前浏览器记住选择，个人和团队空间共用这一设置。
- 账号菜单的「工作流弹框默认全屏（实验性）」默认关闭，当前浏览器记住选择，个人和团队空间共用。开启后，新打开的桌面工作流详情默认铺满可视区。手动退出全屏时，当前详情恢复弹框尺寸，下次从列表打开仍采用菜单设置。链接中的 `view=fullscreen` 或 `view=dialog` 优先于浏览器设置。

## 团队空间

- 用现有账号打开右上角账号菜单中的「切换空间」，可在个人空间和已加入的团队之间切换。选中团队时，个人头像右下角显示团队头像，账号菜单位于同一入口并显示队名和当前账号角色。切换时保留正在浏览的模块及「我的」栏目。选择「创建团队」后再填写名称，新团队从空空间开始。打开自己有权管理的工作流或素材，点「复制到团队」可将所选工作流版本另存为团队草稿，或将素材存入团队资产库。复制后，两边的记录分别管理。
- 管理员和所有者可从右上角账号菜单打开「团队资料」，使用和个人资料相同的选图、裁剪及更换流程，也可以移除团队头像或修改队名。没有自定义头像时显示队名首字。改名后原团队链接仍然有效。
- 「公开团队主页」默认关闭，由管理员或所有者在「团队资料」保存公开设置。开启且有公开内容时，访客可查看队名、团队头像和已发布的工作流与作品。参数及参考素材沿用作品发布时选定的范围。关闭主页、归档团队或撤回最后一项公开内容时，主页和访客的头像访问一并下线。恢复符合公开条件的团队后，原主页地址可再次访问。
- 公共库卡片用开启主页的团队头像和队名署名。详情中的团队名通往公开团队主页，作者名通往个人作者页。作品按成品所属团队署名，团队主页的卡片显示个人作者。访客可直接打开主页，已登录用户的收藏和生成归当前选中的空间。
- 团队用同一套栏目承载内容。角色授予整个空间，覆盖现有及以后加入的栏目和记录。查看者可浏览详情、预览和下载有权访问的原件。编辑者还可导入 ComfyUI JSON 或用团队连接导入 RunningHub 工作流、编辑工作流资料与版本、上传素材和维护团队收藏。
- 「团队成员」显示头像、昵称、账号和角色，并标出当前登录的成员。管理员可按已有账号名添加查看者和编辑者，在成员行调整这两种角色，或打开操作菜单移除成员。所有者还可任免管理员、向已有成员转让所有权及归档团队。每个使用中的团队有一个所有者。所有者退出团队或注销账号前须先转让仍在使用的团队。
- 团队保留内容的创建者和变更操作者记录。成员退出、被移除或注销后，团队内容继续保留，原成员随即失去该团队私有详情和媒体的读取权限。归档后团队页面和已公开的团队内容都停止访问，记录继续保留。
- 管理员和所有者可从右上角团队菜单打开「操作记录」，按操作者、操作类型和日期查看当前团队的历史。列表显示时间、操作者和可辨认的操作对象。成员离开或对象删除后保留记录，注销账号以匿名状态显示。
- 所有者归档前需先处理排队或执行中的任务。归档后，所有者可从「切换空间」底部的「已归档团队」恢复原团队。成员及角色、团队内容、任务历史和工作机配置随原空间恢复，归档前已发布的工作流和作品重新公开。恢复确认会提示旧归档中的排队任务可以继续领取。自助恢复以当前所有者账号为准。
- 工作流卡片的收藏状态跟随当前空间。编辑者及以上成员可把公开工作流和本团队工作流加入团队收藏，每条工作流在本团队计一次。公开工作流在团队收藏中展示发布版本。上传工作流封面时，图片随该工作流保存。要把图片保存在资产库，请使用资产库的上传入口。
- 切到团队后，在同一个「工作机」页面查看团队的 ComfyUI 工作机和 RunningHub 连接。管理员和所有者可接入和管理工作机，也可添加、更新和撤销团队的 RunningHub 连接。接入确认页显示目标空间，并可打开同一个「切换空间」弹框。每个空间独立维护工作机、连接及默认设置。
- 编辑者、管理员和所有者从现有工作流详情提交团队生成。团队工作流可以试跑草稿，公共库中的工作流使用其发布版本。ComfyUI 使用团队工作机，RunningHub 使用团队中同站点的连接，公开的 Atlas Cloud 官方工作流走同一个官方队列。RunningHub 生成费用计入所选连接的账号。素材、任务、执行和成品归当前团队，记录保留实际提交人。编辑者可以取消自己的任务，管理员和所有者可以管理团队任务。
- 管理员和所有者沿用个人版的「发布工作流」和「发布作品」入口。最新草稿先在团队成功执行，再发布工作流。作品从「结果」选择成品，并沿用同一组选项控制公开参数和参考素材。公共库显示已发布的版本与作品，团队素材库和完整结果按团队权限读取。
- 团队空间的账号菜单显示「团队作品」，工作流详情显示「团队结果」。生成面板和任务详情使用同一个补跑入口。管理员和所有者可补跑团队任务中确认需要重做的执行。

## 项目

- 顶部「项目」用瀑布流卡片显示当前空间的项目。卡片显示名称、简介和创建日期，优先预览最近有图像或视频的成功结果，其次使用项目关联的参考素材。点「新建项目」填写名称和可选的简介，创建后进入项目详情。切换空间时返回目标空间的项目列表。
- 在详情页点项目名左侧的菜单图标可切换项目。当前项目列在第一项并打勾，向下滚动可查看当前空间的其他项目。切换时继续查看所选栏目，点击顶部导航「项目」返回列表。
- 在项目详情打开「项目操作」，选择「编辑项目」可修改名称和简介，原项目链接继续有效。选择「归档项目」后，项目从进行中列表和生成选项移出，已提交任务继续执行。项目列表的「项目状态」可切到「已归档」查看原内容，在详情选择「恢复项目」可继续关联资料和提交生成。
- 「删除项目」将项目从列表移除，工作流、参考素材、任务、结果和作品仍可在原空间使用。删除后点通知中的「撤销」，可恢复项目原来的状态和保留的关联。
- 项目详情包含结果、作品、任务、工作流和参考素材。切到「工作流」或「参考素材」，在上方工具栏关联当前空间的工作流、公共工作流或资产库中的参考素材。已关联内容以瀑布流卡片展示。同一条记录可以关联到多个项目，移除关联后原记录仍可使用。
- 重新打开工作流或素材选择弹框时，从空搜索和入口的默认筛选开始。生成表单和「归入项目」共用项目选项，滚动或点击「加载更多」时可继续在同一个下拉菜单中选择。
- 从项目点「选工作流生成」时，默认选中当前项目。从公共工作流库直接打开工作流时默认「无项目」。在生成表单中可改选或新建项目，已填的生成参数会保留。在同一空间载入已有结果的参数时，来源任务仍属于进行中的项目就默认选中该项目。
- 任务的一整批结果以及从中发布的作品会出现在同一个项目。在结果或任务详情中点「归入项目」，可移动整批记录。作品的公开范围沿用发布时选择的成品、参数和参考素材。
- 团队查看者和获授权的个人空间访客可浏览项目。团队编辑者可创建项目、编辑进行中项目的名称和简介、管理关联资料、生成和调整自己提交的任务。管理员和所有者还可归档、恢复或删除项目，调整团队成员的任务，并沿用团队作品的发布权限。团队项目的变更会记入操作记录。

## 导入和发布工作流

1. 在「我的 → 工作流」点击「导入工作流」。登录用户可选择 ComfyUI JSON 文件，API 格式可运行，编辑器格式可保存和下载。当前空间有可用连接时，面板还提供对应平台的链接或 ID 导入。个人空间内，维护账号与获授权账号可导入官方服务清单 JSON。面板中的分类用于新导入的工作流，列表工具栏的「全部分类」用于筛选已有工作流。
2. 在详情里选择在线且已同步节点定义的工作机。默认工作机离线时，为本次任务改选。平台根据工作流和工作机的节点定义生成参数表单。作者可用「编辑参数」调整分组、名称、提示、控件和默认值。
3. 填好参数并提交。任务在选定的工作机上成功执行后，作者可以发布此次使用的最新草稿版本。
4. 用「编辑工作流」上传新版本时，新版本作为草稿保存。访问公共库的其他用户继续使用已发布的版本。待草稿成功执行一次并由作者发布后，公共库切换到新版本。

首页可搜索和筛选公共工作流。分类包括图像、图像工具、视频、视频工具、音频、3D模型、矢量、LLM、节点基础、产品与广告、角色与时尚、品牌与设计，作者可在导入或编辑时选择。通过工作流详情可以打开作者页面，查看对方公开的工作流和作品。工作流详情提供分享链接，链接访问沿用工作流权限。浏览器无法自动复制时，弹框会显示可手动复制的完整链接。

桌面工作流详情右上角的「全屏」将弹框铺满浏览器可视区。「退出全屏」恢复原尺寸，并保留当前版本、已填写的参数、参考素材和正在看的结果。全屏的作品和结果以普通弹框的卡片宽度为参照，空间足够时增加列数，各列均分可用宽度，条目较少时留出空列。手机窄屏默认铺满可视区。全屏和手机窄屏隐藏翻页条，从工作流列表打开时仍可用键盘左右方向键切换相邻工作流。在全屏模式下复制的工作流链接包含 `view=fullscreen`，打开链接会直接以全屏显示。

官方模板可通过 Skill 从对应模板包的 `templates/index.json` 带入分类、校正已有条目并准备默认素材。素材按索引记录的固定版本获取。原始索引省略素材版本时，用 `--source-revision` 提供该索引来源的完整 Git 提交 SHA。素材匹配当前工作流版本和所选工作机的表单。见 [平台操作](../integrations/skills/comfyshop/references/operations.md#工作流)。

## 接入工作机

- 用工作机能访问的平台地址打开「工作机」页并下载启动包。打开 ComfyUI 后运行启动脚本，并登录平台确认接入。无桌面环境时，使用脚本显示的二维码或地址打开确认页。确认页列出申请时间、来源地址和核对提示。确认后页面显示等待状态，工作机领取密钥后显示已接入并自动更新列表。
- 也可手动添加工作机并下载含 API Key 的 `worker.json`。已配置有效密钥时，工作机启动后直接连接。具体安装步骤见 [工作机接入](../integrations/comfyui/README.md)。
- 账号可以连接多台工作机。工作机操作菜单可「设为默认」，默认标记显示在名称旁。生成表单也可为本次任务选择工作机。工作机只领取指定给它的本账号任务。
- 工作机列表用图标区分 Windows、macOS 和 Linux。尚未上报系统的工作机显示通用电脑图标。桌面在名称下方显示设备和版本，右侧并排显示连接状态和接单状态。手机在名称下方显示两种状态，空间不足时换行。点名称可查看设备和版本。暂停或恢复接单时卡片保持原位。
- 在工作机操作菜单选择「暂停接单」后，已领取的任务继续执行并回传。这台工作机在线时可以提交新任务排队，选择「恢复接单」后按队列顺序领取。暂停设置保存在平台，工作机重连后仍有效。
- 重置密钥结束该工作机正在执行的任务，排队任务等新密钥接入后可以继续领取。撤销工作机同时结束分配给它的排队任务。
- 工作机列表将已撤销的工作机排在最后，同组按创建顺序排列。可对已撤销的工作机重置密钥以重新接入，也可在操作菜单中选择「删除工作机」将其移出列表。历史任务保留工作机名称。
- 在操作菜单选择「重命名」可修改工作机的显示名。「我的 → 任务」列表和任务详情都显示关联工作机的最新名称。工作机撤销并删除后，两个入口仍显示删除前的名称。
- 工作机上报实际运行版本。平台发布兼容的签名版本后，可在工作机操作菜单选择「更新到最新版」。当前任务及成品回传完成后获取当时的最新版。下载时若发布切换，工作机重新获取。校验、安装或启动失败时，工作机回到本机原版本，按接单设置领取任务。
- 点击工作机名称打开详情，查看设备、最近上报的操作系统和运行版本、节点数、最近联络时间、更新和接单状态、当前任务及排队任务数。当前任务是这台工作机已领取且租约仍有效的任务，可直接打开它的任务详情。排队数计入分配给这台工作机且尚未领取的任务。
- 工作机页分别显示平台连接和接单状态。已连接的工作机可显示 ComfyUI 未响应、等待本机任务、平台任务占用、已暂停接单或正在更新。详情显示 ComfyUI 状态与最近一次节点目录同步时间。首次收到探测结果前，ComfyUI 状态显示为未知。
- 独立启动包可安装为当前系统账号的后台服务，设置随用户登录或用户服务管理器启动。工作机详情还显示最近一次上报的启动错误。

## 提交和跟踪任务

- 生成区会提示待处理的必填项或无效参数。点「处理参数」可前往对应字段或待处理列表。当前空间没有匹配的工作机或连接时，生成区提供工作机入口。
- 扩图工作流选图后，可在素材旁打开全屏的「扩图范围」。拖动画布的边缘或四角调整尺寸，拖动原图调整位置。顶栏中央的工具条排列快捷比例、居中、撤销、重做和还原，窄屏时在标题下方换行。尺寸和原图占比固定浮在画布底部中央，随调整实时更新。点「精确边距」打开四边像素输入，边距按工作机的步长对齐。右上角的「应用」将边距写入本次参数，「取消」丢弃本次编辑。
- 直接读取原图的 `ImageCrop` 可在素材旁打开「裁剪范围」。拖动选框定位，拖边或角调整范围，选择比例后保持比例，再点一次恢复自由调整。方向键微调 1 像素，配合 Shift 移动 10 像素。确认后将原图坐标和宽高写回本次参数。
- 连续的 `ImageCompositeMasked` 合成可在底图旁打开「图层布局」。选中前景后可拖动定位；接有 `ImageScaleBy` 时拖边或角等比缩放，接有 `ImageRotate` 时可顺时针旋转 90°。支持与前景配对的透明通道。顶栏可选择重叠的图层，「应用」一次写回各层参数。
- 在结果详情打开「对比原图」，拖动分界线查看生成前后，支持缩放以及键盘调整。系统根据提交时的工作流定位此份成品的底图、裁剪位置或扩图边距，使用当前空间可读取的原素材；只有能确认画面位置与尺寸对应的图片成品才显示此入口。
- 局部重绘工作流选图后，可在参考图旁打开全屏的「编辑遮罩」。用「加选」「减选」点取图中物体，或从「人像分区」选择头发、面部皮肤、衣服和背景。选区可继续用画笔和橡皮擦修正，点选、分区和笔画共用撤销、重做和清空。识别失败时可重试或继续手工编辑。点「应用」将与原图同尺寸的 PNG 保存到当前空间并填入本次遮罩参数。再次打开可继续编辑，替换或移除参考图会清空本次配对的遮罩。点「生成」才提交重绘任务。支持两个独立载入节点，也支持同一个 `LoadImage` 同时提供图片和遮罩。
- 图片成品详情和单张生成结果的「局部重绘」直接用当前成品作底图。优先沿用生成这张图片的工作流版本。有一个可用的来源重绘输入时直接打开遮罩画布。存在多个可用工作流时复用项目的工作流选择器，可切换「公共工作流」与「当前空间的工作流」、搜索并点选卡片。只有一个时自动进入。工作流有多个可重绘的参考图输入时，可选择要填的字段。点「应用」回到所选版本的生成表单，参考图和遮罩都已填好，可继续改提示词。
- 扩图和遮罩画布支持围绕指针滚轮缩放、按住空格拖动，以及手机双指缩放和平移。点画布上的缩放百分比可放大、缩小或恢复适合画布。缩放比例以适合画布为 100%，参数按原图像素计算。
- 官方工作流可在「生成」旁显示本批预计费用。平台使用当前版本、填写的参数和参考素材向模型供应商询价，变更时长、分辨率等参数会刷新报价。只改执行次数时按当前单次报价重算总价。Atlas Cloud 报价使用实际计费账号的美元价格，按用量计费的模型会提示实际结算规则。
- 报价需要使用私有参考素材时，先点「估算费用」再发送本次选中的文件。换素材后可重新发起估价。报价暂不可用时，可以重试或继续生成。点「生成」才创建排队任务。个人和团队共用生成入口，团队报价需要生成权限。
- 生成表单、「本次参数」和任务详情的工作机选项都显示名称和状态。提交新任务时，平台复查所选工作机在线。在线但忙碌或暂停接单的工作机可以排队。任务入队后若工作机掉线，会等原工作机重新上线并领取。
- 官方任务的失败原因按查看任务时的展示语言显示，历史任务也适用。Atlas Cloud 明确报告生成超时时可补跑；工作机等待成品超时或未能确认提交时，提示用户先核实生成结果。
- 自有工作机的排队任务详情显示等待原因和前方尚未领取的平台任务数，可进入当前工作机详情。尚未领取的任务可以手动换到同一账号的另一台在线工作机。平台在目标机校验冻结的执行图和输入，通过后将任务加入目标队尾。任务原提交时间和各次执行的种子保留。
- 官方任务在生成面板和「任务详情」显示前方任务数，排在队首时显示 0。使用同一执行适配器的官方工作流在各账号间共用队列。前方数量包含等待领取的任务，以及租约已到期、等待接管的任务。提示会说明官方工作机正在处理其他任务、正在等待领取，或近期未收到接单请求。
- 执行中的官方任务租约到期后，生成面板和「任务详情」显示「等待官方工作机接手」。工作机接手后，两个入口显示「官方工作机已接手」和当前执行阶段。接手的工作机再次掉线且租约到期时，提示回到等待接手。任务结束后显示最终结果。
- 官方任务详情按发生顺序列出每段接管等待的起止时间、等待时长和结果。从旧租约到期开始计时，工作机接手或任务在等待中结束时停止计时。正在等待的时长随进度刷新。任务完成、失败或取消后仍可查看各段记录。一个批次共用一份任务租约和接管记录。
- 每次提交固定工作流版本、输入定义、参数及参考素材，可选择执行 1–32 次。相同输入的多次执行使用平台冻结的种子。对识别出的种子字段，从所选值逐次加一，超出字段上限后回到下限。
- 官方任务的多次执行可并发生成，与其他任务共用实例的并发上限。生成面板显示已完成次数。某次执行失败后，工作机停止发起该任务中尚未开始的执行，继续回收已开始执行的成品。可以补跑已确认失败或尚未提交的执行，提交结果不明确的执行需要核对。
- 工作机已同步图中所有节点类型且能识别输出节点时，表单和任务执行图只使用输出依赖的节点，包括连接到任一输出的素材输入。如果缺少节点类型，平台保留全图，表单列出缺失节点，提交返回 HTTP 409。可在工作机安装并同步相应节点，或确认该节点不需要后从工作流图中移除。
- 文本参数默认最多接受 65,536 个字符。官方模型可以通过字段的 `maxLength` 单独设置限制，最高 4,194,304 个字符。默认值和本次提交的值使用该字段的同一限制。
- 浮点参数可以使用工作机允许范围内的值。节点声明的步长用于滑块和数字输入框的步进。
- 工作机领取后检查需要的节点和模型，调用本机 ComfyUI，回报进度、错误及成品。「任务详情」可在生成面板或「我的 → 任务」打开，包含执行过程、提交参数和已回传结果。
- 未被工作机领取的任务可取消并撤销取消。恢复排队需要原工作机仍可用且引用素材仍存在。执行中的任务可停止，已完整回传的结果继续保留。租约过期后平台根据已收到的执行清单结算。
- 已领取的批次失败或停止后，任务详情逐次显示待核对、补传中或待补跑。原工作机能确认输出时，补传到原执行。确认需要重新执行的次数可用「补跑剩余次数」提交给一台在线的自有工作机，沿用原版本、参数、素材和每次原种子。已提交过补跑的执行会显示在原批次里。
- 参考图像、视频、音频和 GLB 模型默认私有。素材选择器按字段显示可用格式，提交时平台复核已上传文件的格式。相同账号重复上传相同内容时复用素材。配额、单文件上限和未引用素材保留期见 [环境变量](../.env.example)。

## 资产库

- 「我的 → 资产库」可以上传、搜索、按类型筛选、预览和下载私有素材，支持平台接受的图片、视频、音频和 GLB 模型。
- 空资产库显示提示，有编辑权限的用户可直接上传。首份素材入库后，所有有权浏览的用户都可使用搜索和类型筛选。
- 可以将表单里当前空间的素材和可作为输入的生成成品存入资产库。工作流素材字段的「从资产库选择」只列出该字段支持的文件格式。
- 已保存的素材持续保留并计入空间素材配额。移出资产库时，已有任务引用的素材交由任务的保留规则管理。没有任务引用时释放素材记录和存储配额。
- 右上角头像菜单的「空间用量」用容量条显示当前空间的素材占用比例，并列出已用、剩余和上限。个人和团队共用这一展示。用量按计入配额的原件计算，同一原件计一次，仍由任务保留的素材可继续占用配额。
- 实例维护者可以按团队 ID 设置素材上限。个人和未单独设置的团队采用实例默认值。上传、复制、复用任务素材和恢复记录按所属空间的生效额度校验。降低上限后，已存内容仍可读取。[部署配置](deployment.md#compose-启动)

## 查看、发布和重跑成品

- 「我的 → 结果」按单次执行展示私有成品。支持的音频可直接播放和下载。内嵌资源的 GLB 模型可用鼠标或触控旋转、缩放。GLB、FBX、OBJ、MTL、STL、USDZ、3MF 和供应商返回的模型 ZIP 成品可下载原件。「生成参数」显示这次使用的版本、实际输入和参考素材。同一任务后续执行失败时，此前成功的执行仍可查看。
- 可按提交时的工作流名称和浏览器本地日期筛选结果。日期筛选使用站内日历，可单独清除日期。单次结果可点「查看来源任务」，关闭任务详情后回到原结果和筛选条件。
- 打开结果或作品中的视频成品后，可按空格切换播放和暂停，放大查看时也可使用。其他视频预览在播放器取得焦点后支持同一快捷键。
- 音频预览与视频共用播放、静音和进度控件。
- 发布作品时，从自己一次成功执行中选取成品、封面和公开范围。此执行的工作流版本必须已经发布。网页默认推荐「公开完整输入（含素材）」并列出本次会随作品公开的参考文件。也可选择「公开参数」或「仅公开成品」。访客可以下载作品中公开的参考素材。
- 在「我的结果」的执行详情中可上传封面图片、选择本次成品或恢复默认。默认优先取本次执行的图片，其次取视频首帧。也可以在视频预览中选择「用当前画面作组封面」。音频结果卡片优先显示自己的封面图片，没有可用图片时使用通用音频封面。音频和 3D 模型没有封面图片时用文件名区分，音频有时长记录时一并展示。
- 发布时可预览随作品公开的封面，默认沿用结果封面中的图片，或从所选成品中取封面。只有文本成品时，可直接用首个所选文本文件作为封面占位。同次执行的其他图片可以仅作为封面公开缩略图。已发布作品可以独立更换封面。音频和 3D 成品卡片标明文件格式，详情提供原件下载。音频和 GLB 可在详情中播放或预览。
- 工作流封面可从作者已公开的作品中指定。未指定时取最近的作者公开作品。还没有公开作品时，作者本人可看到最近成功执行的成品封面。音频分类的工作流卡片优先显示可用的封面缩略图，缺少缩略图时使用通用音频封面。修改被工作流使用的作品封面会同步更新工作流入口。
- 工作流详情的「作品」「我的结果」、生成表单和任务摘要随所选版本切换。历史公开作品保留原链接，打开链接会进入作品生成时的版本。「载入参数」可回填本人结果的输入或作品公开的输入。从作品直链载入时，表单沿用该作品的来源版本。作者公开的参考素材可以直接用于生成。提交时按当前账号配额登记使用的素材。
- 作者页的公开「作品」只展示来源工作流当前发布版本的作品。「我的 → 作品」可管理各版本作品。两个列表均可按来源工作流的分类筛选。
- 工作流、作品、已结束的任务和成品支持软删除，操作后的通知提供「撤销」。当前弹框或页面就绪后，读屏自动播报操作状态和可用的操作提示。删除确认退出后，如果仍有详情弹框，焦点移到其中的「撤销」。带操作的通知显示到已操作、关闭或被下一条通知替换。按 F8 可前往通知，再用 Tab 聚焦操作。有作品引用的成品需先处理引用。参与删除的素材在保留期内仍可随记录恢复，恢复需满足账号存储配额。

## 从外部客户端使用

Codex 和 Claude Code 的 Skill 可以使用官方模型。工作流的 `format` 为 `service` 时，用 `form <工作流ID> --service` 读取参数并直接提交到官方队列。按以前的执行或作品重跑时可指定来源及版本。见[生成与重跑](../integrations/skills/comfyshop/references/generation.md)。

打开「账户 → 安装 Skill」或直接访问安装页 `/skill`，选择 Codex 或 Claude Code 和终端类型，复制安装命令。客户端通过自己的 ComfyShop 会话登录，可以查询、生成、重跑、发布和管理同一个账号的数据。不同输入组合各提交一条任务，相同输入也可用一条任务重复执行。各项操作见 [Skill 用法](../integrations/skills/comfyshop/SKILL.md) 和 [平台操作](../integrations/skills/comfyshop/references/operations.md)。

## 支持范围

平台使用 ComfyUI 导出的 API JSON 和工作机同步的节点定义生成表单。素材默认支持 PNG、JPEG、WebP、GIF、MP4、WebM、FLAC 和 GLB。声明了具体格式的 Atlas Cloud 素材字段按模型配置选取文件。ComfyUI 工作机可回传图像、视频、FLAC 音频和 GLB 模型。复杂动态嵌套输入和编辑器子图的自动转换超出当前支持范围。跨工作机重跑的输出取决于各工作机的模型、节点和执行环境。
