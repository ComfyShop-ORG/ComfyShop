# ComfyShop

从用户当前工作目录调用 Skill 随附的 `scripts/comfyshop.py`，使用脚本的绝对路径。macOS 和 Linux 用 `python3`，Windows 用 `py -3`。安装时配置的站点保存在 `platform.json`。

- 用 `account` 核对平台地址和账号。公开内容可在访客会话下查询。需要注册、登录或退出时，给用户相应的终端 `register`、`login` 或 `logout` 命令。账号和密码由用户在终端输入。
- 以平台返回的记录 ID、版本和状态为准。先定位目标。只在重名、缺少必填内容或公开范围不明确时请用户补充。
- 发布、取消或删除任务及其他记录、重置或撤销工作机密钥，按用户明确指定的对象和范围执行。平台报冲突时，核对实际状态与原因。只有具备幂等契约的请求可原样重试，其余请求先查询服务器确认结果。
- 工作机完整密钥保存在仓库外的本地连接配置中。回复提供配置路径和工作机信息。

## 按任务选择说明

- 规划、生成、重跑、查询进度和下载结果，读[生成与重跑](references/generation.md)。
- 导入、编辑、分享或发布工作流，管理收藏、任务、成品、作品、工作机和个人资料，读[平台操作](references/operations.md)。使用 `operations` 查询当前脚本支持的操作和参数。
