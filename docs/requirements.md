# 功能与使用

ComfyShop 是面向团队的开源自托管 RunningHub 替代方案，覆盖 ComfyUI 工作流发布、工作机接入、生成任务、逐次执行和成品管理。Web 和 Skill 通过同一个 FastAPI 服务访问平台数据。 [RunningHub 中国站](https://www.runninghub.cn/) · [RunningHub 国际站](https://www.runninghub.ai/)

## 账户与访问

- 在登录弹框用账号和密码注册。邮箱选填，确认后用于找回密码。通过「账户 → 账号设置」可管理邮箱、修改密码或注销账号。
- 「账户 → 个人资料」可保存最多 32 个字符的昵称，留空时显示账号名。选择不超过 5 MB、2000 万像素的 JPG、PNG 或 WebP 后，在上层弹框中拖动、缩放并预览方形裁剪。点「保存头像」后立即更新，点「取消」返回个人资料。昵称单独保存，头像也可移除。账号菜单、作者页、工作流和作品显示更新后的资料。登录与作者链接继续使用账号名。作者发布工作流或作品后，访客可查看作者资料。
- 更换邮箱需打开新邮箱里的链接，点「确认绑定」。确认前已绑定的邮箱仍可用于找回密码。修改密码、管理邮箱和注销均需核对当前密码。
- 登录时可点「忘记密码」，使用已绑定的邮箱申请一次性链接。密码重置链接默认有效 30 分钟，邮箱确认链接默认有效 24 小时，可通过 [环境变量](../.env.example) 配置。未设置邮件服务时，链接写入服务日志。
- 修改密码会注销其他会话，重置密码会注销所有会话。两者都会撤销工作机密钥和待兑换的接入申请。注销会隐藏账号的工作流、作品、任务和成品，同时撤销工作机和会话。
- 访客可浏览公共工作流和公开作品。生成、收藏、上传、发布和下载工作流 JSON 需要登录。
- 首次访问默认使用深色。访客和登录用户都可以通过页头右侧的太阳或月亮按钮切换全站外观。当前浏览器记住选择，刷新和退出登录后继续使用。

## 导入和发布工作流

1. 在「我的 → 工作流」导入 ComfyUI JSON。运行需要 ComfyUI 导出的 API JSON，编辑器 JSON 可保存和下载。
2. 在详情里选择已同步节点定义的工作机。平台根据工作流和工作机的节点定义生成参数表单。作者可用「编辑参数」调整分组、名称、提示、控件和默认值。
3. 填好参数并提交。任务在选定的工作机上成功执行后，作者可以发布此次使用的最新草稿版本。
4. 用「编辑工作流」上传新版本时，新版本作为草稿保存。访问公共库的其他用户继续使用已发布的版本。待草稿成功执行一次并由作者发布后，公共库切换到新版本。

首页可搜索和筛选公共工作流。分类包括图像、图像工具、视频、视频工具、音频、3D模型、矢量和 LLM，作者可在导入或编辑时选择。通过工作流详情可以打开作者页面，查看对方公开的工作流和作品。工作流详情提供分享链接，链接访问沿用工作流权限。浏览器无法自动复制时，弹框会显示可手动复制的完整链接。

官方模板可通过 Skill 从对应模板包的 `templates/index.json` 带入分类、校正已有条目并准备默认素材。素材按索引记录的固定版本获取，匹配当前工作流版本和所选工作机的表单。见 [平台操作](../integrations/skills/comfyshop/references/operations.md#工作流)。

## 接入工作机

- 用工作机能访问的平台地址打开「工作机」页并下载启动包。打开 ComfyUI 后运行启动脚本，并登录平台确认接入。无桌面环境时，使用脚本显示的二维码或地址打开确认页。确认页列出申请时间、来源地址和核对提示。确认后页面显示等待状态，工作机领取密钥后显示已接入并自动更新列表。
- 也可手动添加工作机并下载含 API Key 的 `worker.json`。已配置有效密钥时，工作机启动后直接连接。具体安装步骤见 [工作机接入](../integrations/comfyui/README.md)。
- 账号可以连接多台工作机。在「工作机」设置默认项，生成表单也可为本次任务选择工作机。工作机只领取指定给它的本账号任务。
- 重置密钥结束该工作机正在执行的任务，排队任务等新密钥接入后可以继续领取。撤销工作机同时结束分配给它的排队任务。
- 工作机上报实际运行版本。旧启动包显示「版本未知」。平台发布兼容的签名版本后，可在工作机操作菜单选择「更新到最新版」。当前任务及成品回传完成后获取当时的最新版。下载时若发布切换，工作机重新获取。校验、安装或启动失败时，工作机回到本机原版本并继续领取排队任务。

## 提交和跟踪任务

- 每次提交固定工作流版本、输入定义、参数及参考素材，可选择执行 1–32 次。相同输入的多次执行使用平台冻结的种子。对识别出的种子字段，从所选值逐次加一，超出字段上限后回到下限。
- 工作机能识别输出节点时，表单和任务执行图只使用这些输出依赖的节点，包括连接到任一输出的素材输入。
- 每个文本参数最多接受 65,536 个字符，图内默认值和显式提交都使用这个限制。校验失败时显示节点和参数名称。
- 浮点参数可以使用工作机允许范围内的值。节点声明的步长用于滑块和数字输入框的步进。
- 工作机领取后检查需要的节点和模型，调用本机 ComfyUI，回报进度、错误及成品。「任务详情」可在生成面板或「我的 → 任务」打开，包含执行过程、提交参数和已回传结果。
- 未被工作机领取的任务可取消并撤销取消。恢复排队需要原工作机仍可用且引用素材仍存在。执行中的任务可停止，已完整回传的结果继续保留。租约过期后平台根据已收到的执行清单结算。
- 参考图像、视频、FLAC 音频和 GLB 模型默认私有。相同账号重复上传相同内容时复用素材。配额、单文件上限和未引用素材保留期见 [环境变量](../.env.example)。

## 查看、发布和重跑成品

- 「我的 → 结果」按单次执行展示私有成品。FLAC 音频可直接播放和下载。支持内嵌资源的 GLB 模型预览，鼠标或触控可以旋转、缩放，并可下载原件。「生成参数」显示这次使用的版本、实际输入和参考素材。同一任务后续执行失败时，此前成功的执行仍可查看。
- 发布作品时，从自己一次成功执行中选取成品、封面和公开范围。此执行的工作流版本必须已经发布。网页默认推荐「公开完整输入（含素材）」并列出本次会随作品公开的参考文件。也可选择「公开参数」或「仅公开成品」。访客可以下载作品中公开的参考素材。
- 在「我的结果」的执行详情中可上传封面图片、选择本次成品或恢复默认。默认优先取本次执行的图片，其次取视频首帧。也可以在视频预览中选择「用当前画面作组封面」。音频和 3D 模型没有封面图片时用文件名区分，音频有时长记录时一并展示。
- 发布时可预览随作品公开的封面，默认沿用结果封面中的图片，或从所选成品中取封面。同次执行的其他图片可以仅作为封面公开缩略图。已发布作品可以独立更换封面。FLAC 和 GLB 的卡片保留媒体类型，详情提供原件播放或交互预览及下载。
- 工作流封面可从作者已公开的作品中指定。未指定时取最近的作者公开作品。还没有公开作品时，作者本人可看到最近成功执行的成品封面。修改被工作流使用的作品封面会同步更新工作流入口。
- 工作流详情的「作品」「我的结果」、生成表单和任务摘要随所选版本切换。历史公开作品保留原链接，打开链接会进入作品生成时的版本。「载入参数」可回填本人结果的输入或作品公开的输入。作者公开的参考素材可以直接用于生成。提交时按当前账号配额登记使用的素材。
- 作者页的公开「作品」只展示来源工作流当前发布版本的作品。「我的 → 作品」可管理各版本作品。两个列表均可按来源工作流的分类筛选。
- 工作流、作品、已结束的任务和成品支持软删除，操作后的提示条提供「撤销」。有作品引用的成品需先处理引用。参与删除的素材在保留期内仍可随记录恢复，恢复需满足账号存储配额。

## 从外部客户端使用

打开「账户 → 安装 Skill」或访问 `/skill`，选择 Codex 或 Claude Code 和终端类型，复制安装命令。客户端通过自己的 ComfyShop 会话登录，可以查询、生成、重跑、发布和管理同一个账号的数据。不同输入组合各提交一条任务，相同输入也可用一条任务重复执行。各项操作见 [Skill 用法](../integrations/skills/comfyshop/SKILL.md) 和 [平台操作](../integrations/skills/comfyshop/references/operations.md)。

## 支持范围

平台使用 ComfyUI 导出的 API JSON 和工作机同步的节点定义生成表单。素材和成品支持图像、视频、FLAC 音频和 GLB 模型。复杂动态嵌套输入和编辑器子图的自动转换超出当前支持范围。跨工作机重跑的输出取决于各工作机的模型、节点和执行环境。
