# 设计规则

## Tokens 优先

`packages/tokens/src/tokens.json` 是唯一来源。`color` 提供默认深色，`lightColor` 为浅色覆盖同名的语义变量。构建生成两套 Web CSS Custom Properties 和 API 的 `design_tokens.py` 邮件调色板，同时导出 TypeScript 布局参数。改动配色后运行 `pnpm tokens`，如有生成文件差异一起提交。`pnpm check` 会报告生成的调色板是否过期。组件使用语义变量并定义结构、状态与组合关系。

Web 入口按 tokens、ui、media、页面的顺序加载样式。UI 包使用全局 CSS 变量和 tokens 包提供的品牌图形，媒体包使用 tokens 包的 TypeScript 布局参数。

颜色分为 canvas、surface、raised、text、muted、accent、focus、danger、warning、success 等用途。主要操作与选中状态在深色主题中用荧光绿，在浅色主题中用深绿色。danger 用于确认删除、失败和错误文字，warning 用于等待中的状态和需要先满足的条件。媒体上方的文字和图标采用深底浅字。所有半径为零。常用字号、间距、控件高度、层级及动效均集中定义。少数响应式容器计算及媒体自身比例属于布局，不为了消除每个数字建立无语义变量。

## Radix 与基础控件

`@comfyshop/ui` 封装 Button、IconButton、Input、TextArea、FileInput、Field、Select、RangeSlider、TrackSlider、DialogContent、DialogClose、ProgressBar 与 Logo，并提供统一样式的 Tabs、Collapsible、ToggleGroup、DropdownMenu、Tooltip、Toast 组合入口。

按照 [Radix 样式指南](https://www.radix-ui.com/primitives/docs/guides/styling) 使用 CSS 及 data-state 管理状态。按照 [Radix 组合指南](https://www.radix-ui.com/primitives/docs/guides/composition) 保留 props/ref 透传及 asChild 能力。

共享 Logo 使用两个 SVG。宽屏导航显示字标，窄屏导航、登录和邮箱确认弹框显示图标，浏览器图标也使用同一图标。运行 `pnpm tokens` 会同步 SVG 的品牌色，并从图标生成 `/favicon.svg`。

FileInput 的 ref 指向文件输入；Select 的 ref 指向触发按钮，Root 属性直接透传，触发按钮属性通过 `triggerProps` 提供。

输入保留原生 input/textarea 的表单、自动填充与键盘语义。触屏设备的输入文字至少为 16 px，避免 iOS Safari 聚焦时自动放大。选择、滑块、弹框和菜单使用 Radix 的可访问性交互。界面不直接使用浏览器默认外观。视频播放由统一媒体预览和共享按钮控制。

工作流表单用 `RangeSlider` 展示配置为滑块的数值字段。共享控件用 `VisuallyHidden` 提供屏幕阅读器可读的说明。功能组件不保留已无调用方的回调。工作流、作品与结果的媒体来自 FastAPI，不捆绑未使用的静态样例图库。

Button 的 `danger` 样式只用于不可随手撤回的确认操作。FileInput 在文件拖到上方时高亮，放下后与点击选择走同一个 onChange。TrackSlider 是不带字段标题的单滑块，用于视频播放位置。

## 状态与过程

- 任务和工作机的状态前带方形色块：进行中用强调色并缓慢明暗变化，可用或已完成用 success，等待用 warning，失败用 danger，其余为中性灰。
- 生成等待用占位画面承载过程：画面比例取自工作流封面，进度自下而上填充，中间显示阶段、百分比和已用时间。成品出现时自下而上展开一次。减少动态效果模式下这些变化即时完成。
- 动效时长为 fast、normal、slow 三档，slow 用于过程和揭示类变化。弹框入场时略微上移并淡入，卡片封面读完后淡入。
- 浮层、提示条、菜单、下拉和折叠区域的开合用 CSS 动画，由 Radix 的 `data-state` 驱动。Radix 以动画名称是否变化判断退出动画，关闭动画使用独立的 keyframes，不复用入场动画的反向播放。
- 需要测量布局的动效使用 motion 库，统一从 `apps/web/src/motion` 引入：`ActiveMark` 让导航、标签和筛选的选中底色在同组内水平滑动；`ListPresence` 与 `ListItem` 让任务和工作机列表在增删时淡入淡出并平滑补位。motion 的功能包按需加载，时长取自 tokens。瀑布流内部不加布局动画。
- 平台邮件使用默认深色调色板，包含深色画布、表格色块绘制的图标、文本品牌名、直角主按钮及纯文本正文。邮件从 API 安装包直接导入生成的 Token 调色板。Logo 由表格渲染，邮件客户端屏蔽图片时仍能显示。
- 按钮按下时轻微缩小。系统开启「减少动态效果」时，CSS 动画与 motion 动画都停用。
- 刚完成的提交只有一次执行时，结果放大展示并直接提供查看发布和下载。弹框内条目少于列数的列表减少列数，让卡片占满宽度。
- 提示条可带一个操作，用于撤销刚才的删除，此时停留更久。

## 视觉验收

- 深色使用黑灰层级，浅色使用灰白画布和白色弹框。两套外观共用直角控件和平面层级，以间距和背景区分区域。
- 首页没有宣传标题与说明段，只有导航、搜索、分类、排序和瀑布流。
- 工作流、作品和结果使用一套媒体卡片与瀑布流；保留原始媒体比例，列表按展示尺寸和屏幕密度选取缩略图，预览和下载保留原文件。
- 电脑悬停时缩略图在卡片内微放大约 2%，标题和卡片尺寸固定。视频卡片在光标停留约 300 毫秒后请求静音短片，播放一次并停在最后一帧，移开光标恢复封面。触屏与减少动态效果模式使用静态封面，点卡片打开详情。
- 结果卡片代表一次执行，数量区分图片与视频；组内继续使用共享瀑布流。选择资产与选择作品封面沿用相同媒体卡片，以选中标记表达状态。
- 登录框紧凑，Logo 与标题同行，账号和密码对齐，小尺寸主按钮靠右；左侧切换步骤的文字按钮与字段左缘对齐。登录、注册、找回密码、查收邮件和设置新密码是同一个弹框的不同步骤，字段旁的次要操作（如「忘记密码」）放在字段标题右侧。
- 账号菜单的「个人资料」独立编辑头像和昵称，各自保存。在上层弹框完成方形裁剪，关闭后焦点回到选图控件。账号设置弹框以账号概要开头，邮箱、密码和注销分组用标签切换。注销前先列出后果，再要求勾选确认。
- 弹框内完成预览、参数设置、工作机选择、提交及结果查看。移动端预览区随内容缩短，长列表在限定高度内滚动。任务筛选、标题和操作按钮可按可用宽度换行，反馈提示保留底部生成操作。
- 公开作品和私有结果共用单件预览与成品详情。手机上关闭按钮位于标题右侧，其他操作可换行。尺寸、原文件下载处于同一操作区，单件可放大，多件可从瀑布流进入单件详情。“载入参数”不会自动提交任务。
- 工作流、作品、执行结果和组内成品在同一个弹框内按来源列表的筛选和排序切换。宽屏箭头位于弹框两侧，窄屏放入独立的底部操作区。焦点在输入、标签或视频控件时，方向键由该控件处理。
- 浏览工作流时，弹框内按工作流和版本暂存输入、参考素材、执行次数和本次工作机。上传和提交期间暂停切换，任务进入队列后即可继续浏览。关闭弹框时清除草稿。
- 工作流详情左侧为“作品 / 我的结果”，右侧为运行表单。生成按钮上方提供当前任务状态和“任务详情”。任务详情内使用“执行过程 / 提交参数 / 结果”切换，单次结果内使用“成品 / 生成参数”切换。“发布工作流”与“发布作品”分别命名。发布作品时直接显示公开范围和将随作品公开的参考文件名。
- 文案只表达名称、标签、操作、状态和必要错误。Worker 统一译为工作机。分享链接通过共享控件复制，剪贴板不可用时提供可选择的完整地址，关闭后焦点回到原触发按钮。
- 键盘操作保留可见焦点，鼠标关闭菜单或选择选项后仍恢复实际焦点。图标提示由悬停或键盘聚焦触发。悬停使用中性背景，选中使用强调色。菜单选项整行可操作。
- 模态弹框有遮罩、标题、焦点约束、Escape 退出和关闭后的焦点恢复。嵌套弹框的遮罩压暗上一层。参数编辑在桌面按列滚动，手机按三个分区顺序滚动。尊重减少动态效果设置。
